# 运营数据导入与复盘

在「数据看板 → 导入数据」操作。先选择平台、数据对象、周期与来源，再手动填写指标或选择 CSV / Excel 文件。账号整体数据不要关联到某条作品；作品数据必须选择对应内容。不会联网获取任何平台数据。

## 文件规则

- 最大 1 MB，每批最多 1000 行，最多 64 列。Excel 读取首个工作表，支持 `.xlsx` / `.xls`，不执行公式，错误或公式单元格所在行会被拒绝。
- 首行是字段名，支持英文标准键和常见中文名：播放量 / 阅读量、点赞数、评论数、分享数、收藏数、粉丝总数、新增粉丝、流失粉丝、净增粉丝、完播率、2秒跳出率、5秒留存率、平均观看时长。
- 特殊列名可展开「字段映射与高级输入」，填写如 `{"阅读次数":"views"}` 的映射。未知或重复映射列会拒绝导入，避免静默错配。
- 正确处理 CSV 引号、逗号、换行；百分比可写 `23.5%`，标准 ratio 数值为 0–1；数量支持千分位、万、亿。空值表示不知道，不是 0。
- 文件内 `platformCode` / `contentId` 优先于界面选项。平台代码固定为 `douyin`、`wechat_channels`、`xiaohongshu`、`weibo`。内容 ID 来自本地内容 API，不是平台作品 ID。
- 日期 `YYYY-MM-DD` 按上海时间解释，开始和结束当天都包含。单行可使用 `periodStart` / `periodEnd` 覆盖整批周期。重复对象、周期取最新采集快照，不累计同一数据的多次导入。
- 导入后检查成功行与失败行。正确行独立保存，坏行不会留下半条指标或复盘。修正后重试；接口调用保留同一幂等键用于同一请求重试，修改了请求内容则使用新键。

## 数据总览的口径

账号总量优先，不和作品数据相加。没有账号数据时，只显示已知作品小计。跨月累计值不会按比例拆分；重叠区间择取可用的不重叠周期，并给出缺口提示。只有实际导入的单日观察才形成趋势点，多日累计不会生成虚构日曲线。粉丝总量不是涨粉，净增只来自明确指标或同一快照的新增减流失。

## 单条作品复盘

从「内容库 → 查看 → 作品复盘」进入。按平台和周期选快照；核心指标、流量生命周期、留存、互动时间分布、流量来源与独立判断分别显示。每张图可展开查看原始点和证据。缺失的图保持空态。

`observed` 为原始数据，`derived` 为计算结果，`inferred` 为推断、不是事实。后两类必须带 `calculationNote` 和非空 `evidence`。概览不会把 inferred 指标计入真实表现。复盘建议可为推断，但这不意味着已提供的原始指标变成推断。

通过 `POST /api/v1/ingestion` 的 `workbuddy` 来源可提交结构化 `metrics`、`series`、`review`；CSV/Excel 的同名列也可保存 JSON。具体字段参见 `app/server/openapi.yaml`，默认映射可查询 `GET /api/v1/ingestion/mapping`。V1 不执行 AI 推理或官方平台调用，`official_api` 仅保留未来适配位置。

测试数据均为明确标注的虚构 FUV 类型结构，只写入操作系统临时目录。既有真实复盘 PDF 仅用于理解布局、口径与证据表达，没有复制其运营数字到测试。
